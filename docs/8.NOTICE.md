8단계: 공지사항 관리 프롬프트
파킹케어 백오피스의 공지사항 관리 기능을 구현해주세요.

📋 기능 요구사항
아파트별 공지사항 등록 및 관리

🎯 주요 기능
1. 공지사항 목록
   - 노출 여부 필터
   - 중요 공지 표시
   - 등록일 정렬

2. 공지사항 등록
   - 제목 입력
   - 내용 입력 (리치 텍스트 에디터)
   - 중요 공지 여부
   - 노출 기간 설정
   - 노출 여부

3. 공지사항 수정/삭제
   - 정보 수정
   - 노출 상태 변경
   - 삭제

4. 미리보기
   - 모바일 앱 화면 미리보기

📊 데이터 모델
interface Notice {
  notice_id: string;
  apt_code: string;
  title: string;
  content: string;
  is_important: boolean;
  is_visible: boolean;
  start_date?: string;
  end_date?: string;
  view_count: number;
  created_by: string;
  updated_at: string;
  created_at: string;
}
