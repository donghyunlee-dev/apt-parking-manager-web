7단계: 차량 조회 및 리포트 프롬프트
파킹케어 백오피스의 차량 조회 및 리포트 기능을 구현해주세요.

📋 기능 요구사항
통합 차량 조회 및 통계 리포트 제공

🎯 주요 기능
1. 통합 차량 조회
   - 차량번호로 검색
   - 차량 타입 표시 (입주민/방문/미등록)
   - 상세 정보 표시
   - 스캔 이력 표시

2. 대시보드
   - 전체 차량 통계
   - 금일 스캔 현황
   - 방문 차량 현황
   - 미등록 차량 통계

3. 차량 스캔 이력
   - 날짜별 스캔 기록
   - 차량별 스캔 패턴
   - Export 기능 (CSV, Excel)

4. 리포트
   - 일간/주간/월간 리포트
   - 미등록 차량 리포트
   - 방문 차량 리포트

📊 데이터 모델
interface VehicleSearchResult {
  vehicle_number: string;
  vehicle_type: 'resident' | 'visitor' | 'unregistered';
  details: ResidentVehicle | VisitorVehicle | null;
  scan_history: ScanLog[];
}

interface ScanLog {
  log_id: string;
  apt_code: string;
  vehicle_number: string;
  scan_date: string;
  scan_time: string;
  vehicle_type: 'resident' | 'visitor' | 'unregistered';
  bouncer_code: string;
}

interface DashboardStats {
  total_resident_vehicles: number;
  total_visitor_vehicles: number;
  today_scan_count: number;
  today_unregistered_count: number;
  active_visitors: number;
  expired_visitors: number;
}
