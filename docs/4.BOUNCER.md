4단계: 경비원 관리 기능 프롬프트
파킹케어 백오피스의 경비원 관리 기능을 구현해주세요.

📋 기능 요구사항
유료 기능으로, 다중 경비원 등록 및 관리가 가능합니다.

🎯 주요 기능
1. 경비원 목록 조회
   - 테이블 형태로 표시
   - 검색 기능 (이름)
   - 사용 여부 필터
   - 페이징 처리

2. 경비원 등록
   - 경비원명 입력
   - 6자리 FIN 번호 자동 생성 또는 수동 입력
   - FIN 번호 중복 검증
   - 사용 여부 설정

3. 경비원 수정
   - 정보 수정
   - 사용 여부 변경

4. 경비원 삭제
   - 확인 다이얼로그
   - 연관된 데이터 처리 안내

📊 데이터 모델
interface Bouncer {
  apt_code: string;
  bouncer_code: string;
  bouncer_name: string;
  fin_no: string;        // 암호화된 상태로 표시 (마스킹)
  used: 'Y' | 'N';
  updated_at: string;
  created_at: string;
}
