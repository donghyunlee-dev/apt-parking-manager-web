6단계: 방문 차량 관리 프롬프트
파킹케어 백오피스의 방문 차량 관리 기능을 구현해주세요.

📋 기능 요구사항
방문 차량 등록, 조회, 수정, 삭제 및 방문 이력 관리

🎯 주요 기능
1. 방문 차량 목록
   - 상태별 필터 (전체/유효/만료)
   - 검색 (차량번호, 방문 호수, 연락처)
   - 날짜 범위 필터
   - 방문 횟수 표시

2. 방문 차량 등록
   - 방문 호수 선택
   - 차량번호 입력
   - 방문자 연락처
   - 방문 기간 설정 (시작일, 종료일)

3. 방문 차량 수정
   - 방문 기간 연장
   - 정보 수정

4. 방문 이력 조회
   - 차량별 방문 이력
   - 기간별 방문 통계
   - 호수별 방문 현황

interface VisitorVehicle {
