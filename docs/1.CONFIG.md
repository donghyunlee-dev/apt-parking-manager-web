1단계: 프로젝트 초기 설정 프롬프트
파킹케어 백오피스 웹 애플리케이션을 React로 개발해주세요.

🎯 프로젝트 개요
아파트 주차 관리 시스템의 관리자용 웹 백오피스입니다.
모바일 앱은 이미 개발되어 있으며, 백엔드 API는 Java로 구현되어 있습니다.

🛠 기술 스택
- React 18 이상
- TypeScript
- Vite (빌드 도구)
- React Router v6
- TanStack Query (react-query) - API 상태 관리
- Zustand - 전역 상태 관리
- Tailwind CSS - 스타일링
- shadcn/ui - UI 컴포넌트 라이브러리

📦 프로젝트 구조
클린 아키텍처 원칙을 따라 다음 구조로 설정해주세요:

src/
├── features/          # 기능별 모듈
│   ├── auth/         # 로그인/인증
│   ├── apartment/    # 아파트 정보 관리
│   ├── bouncer/      # 경비원 관리
│   ├── resident/     # 입주민 차량 관리
│   ├── visitor/      # 방문 차량 관리
│   └── notice/       # 공지사항
├── shared/           # 공통 모듈
│   ├── components/   # 재사용 컴포넌트
│   ├── hooks/        # 커스텀 훅
│   ├── utils/        # 유틸리티 함수
│   └── types/        # 타입 정의
├── api/              # API 인터페이스
│   ├── client.ts     # axios 인스턴스
│   └── mock/         # Mock 데이터
└── routes/           # 라우팅 설정

✅ 초기 설정 작업
1. Vite + React + TypeScript 프로젝트 생성
2. 필요한 의존성 패키지 설치
3. ESLint, Prettier 설정 (Airbnb 스타일 가이드 기반)
4. 폴더 구조 생성
5. 기본 라우팅 구조 설정
6. Tailwind CSS 및 shadcn/ui 설정

package.json에 포함할 주요 의존성:
- react-router-dom
- @tanstack/react-query
- zustand
- axios
- date-fns
- zod (유효성 검증)
- react-hook-form

Mock API를 위한 MSW(Mock Service Worker) 설정도 포함해주세요.
