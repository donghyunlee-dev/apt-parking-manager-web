9단계: UI/UX 개선 및 최적화 프롬프트
파킹케어 백오피스의 UI/UX를 개선하고 성능을 최적화해주세요.

🎯 개선 사항
1. 반응형 디자인
   - 태블릿, 데스크톱 대응
   - 모바일 뷰 최적화

2. 다크 모드
   - 테마 전환 기능
   - 시스템 설정 감지

3. 접근성
   - 키보드 네비게이션
   - 스크린 리더 지원
   - ARIA 속성 추가

4. 사용성
   - 로딩 스켈레톤
   - 에러 바운더리
   - Toast 알림 시스템
   - 확인 다이얼로그
   - 툴팁 추가

5. 성능 최적화
   - 코드 스플리팅
   - 이미지 최적화
   - 메모이제이션
   - 가상 스크롤 (대용량 리스트)

💡 구현 포인트
- React.memo, useMemo, useCallback 적절히 사용
- Lazy loading 적용
- 번들 크기 최적화
- Lighthouse 점수 90+ 목표
- 로딩 시간 최소화

추가 라이브러리:
- react-hot-toast (알림)
- framer-motion (애니메이션)
- react-virtuoso (가상 스크롤)

모든 개선 사항은 성능 저하 없이 구현해주세요.
