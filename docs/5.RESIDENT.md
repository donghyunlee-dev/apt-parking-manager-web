5단계: 입주민 차량 관리 프롬프트
파킹케어 백오피스의 입주민 차량 관리 기능을 구현해주세요.

📋 기능 요구사항
1. 차량 목록 조회 및 관리
2. 차량 일괄 등록 (Excel 업로드)
3. 개별 차량 등록/수정/삭제

🎯 주요 기능
1. 차량 목록
   - 검색 (차량번호, 동/호수, 연락처)
   - 정렬 (등록일, 동/호수)
   - 페이징

2. 차량 등록
   - 동/호수 선택
   - 차량번호 입력 (형식 검증)
   - 연락처 입력
   - 차량 이미지 업로드 (선택)

3. 일괄 등록
   - Excel 템플릿 다운로드
   - Excel 파일 업로드
   - 업로드 결과 표시 (성공/실패)

4. 차량 수정/삭제
   - 정보 수정
   - 삭제 확인 다이얼로그

📊 데이터 모델
interface ResidentVehicle {
  vehicle_id: string;
  apt_code: string;
  building: string;       // 동
  unit: string;          // 호수
  vehicle_number: string;
  phone_number?: string;
  image_url?: string;
  updated_at: string;
  created_at: string;
}
