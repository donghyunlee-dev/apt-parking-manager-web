2단계: 공통 컴포넌트 및 레이아웃 프롬프트
파킹케어 백오피스의 공통 레이아웃과 재사용 컴포넌트를 구현해주세요.

🎨 레이아웃 구조
1. AuthLayout - 로그인 페이지용 레이아웃
2. DashboardLayout - 메인 백오피스 레이아웃
   - 사이드바 네비게이션
   - 헤더 (아파트명, 로그아웃)
   - 메인 컨텐츠 영역

📍 네비게이션 메뉴 구성
- 대시보드
- 경비원 관리
- 입주민 차량 관리
- 방문 차량 관리
- 차량 조회 및 리포트
- 공지사항 관리

🧩 공통 컴포넌트
SOLID 원칙과 클린 코드를 준수하여 구현해주세요:

1. DataTable
   - 정렬, 필터링, 페이징 기능
   - 행 선택 기능
   - 액션 버튼 영역

2. SearchBar
   - 검색 입력
   - 필터 옵션

3. Modal
   - 등록/수정 폼용 모달
   - 확인 다이얼로그

4. FormField
   - Input, Select, DatePicker 등
   - 에러 메시지 표시

5. StatusBadge
   - 상태 표시용 배지 컴포넌트

6. EmptyState
   - 데이터 없음 표시

각 컴포넌트는:
- Props 타입을 명확히 정의
- 단일 책임 원칙 준수
- 재사용성 고려
- 접근성(a11y) 준수
