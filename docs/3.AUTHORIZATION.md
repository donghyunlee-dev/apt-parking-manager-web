🔑 인증 플로우
1. 로그인 화면
   - 아파트 코드 입력 (A0001)
   - 6자리 FIN 코드 입력

2. 인증 상태 관리
   - Zustand로 인증 상태 저장

3. 보호된 라우트
   - 미인증 시 로그인 페이지로 리다이렉트
   - 권한별 접근 제어
